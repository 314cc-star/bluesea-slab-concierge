## Part 2 · อัดหน้าจอเว็บ (20 นาที)

### เตรียมก่อนอัด
1. เปิด https://bluesea-slab-concierge.onrender.com ทิ้งไว้ 1 นาทีก่อนอัด (ให้เว็บตื่น)
2. ใช้ Chrome หน้าต่างเต็มจอ, ซูม 100%, ปิดแท็บอื่น, ซ่อนแถบบุ๊กมาร์ก (Ctrl+Shift+B)
3. เช็กว่าแผ่น BSW-177 ยังขึ้น **Reserve** (ถ้าขึ้น Reserved ให้รอ 30 นาที หรือเปลี่ยนเป็นแผ่นอื่น)
4. เตรียมบัญชีผู้ซื้อทดสอบ (Personal) ของ PayPal sandbox และรหัส /owner ไว้
5. ใช้เบอร์ปลอมตอนกรอก: `081 234 5678`
6. อัดด้วย **Win + Alt + R** (กดอีกครั้งเพื่อหยุด) ไฟล์อยู่ใน Videos\Captures

อัดแยกเป็นคลิปตามช็อตด้านล่าง ทำช้าๆ เว้นจังหวะ 1–2 วินาทีหลังแต่ละคลิก (ตัดทีหลังง่าย)

| # | ทำอะไร (คลิกตามนี้) |
|---|---|
| S1 | หน้าแรก: เลื่อนช้าๆ จากหัวเว็บ → แถบ Our promises → Slab Concierge |
| S2 | กดตัวอย่างคำถาม **"A dining table for 6 people, my room is 3 m wide"** รอ AI ตอบ เลื่อนให้เห็นคำตอบและการ์ดแผ่นไม้ |
| S3 | พิมพ์ `I'll take BSW-177 with steel legs and a durable finish, we have kids` แล้ว Enter รอปุ่ม **Review and pay deposit** |
| S4 | เลื่อนลงไปที่ **Slabs in stock** → กดรูปแผ่น **BSW-177** → ดูรูปไม้ดิบ → กดรูป **Finished example** → ปิด |
| S5 | กลับไปที่แชต กด **Review and pay deposit** → ให้เห็นขาเหล็กและโพลียูรีเทนถูกเลือกไว้แล้ว → ลองกด **Wooden legs** แล้วกลับเป็น **Steel** (ราคารวมเปลี่ยนตาม) |
| S6 | พิมพ์เบอร์ในช่อง Phone → กดปุ่ม **PayPal** สีเหลือง → ล็อกอินบัญชีผู้ซื้อทดสอบ → **Complete Purchase** |
| S7 | หน้ายืนยัน: เลื่อนช้าๆ ให้เห็นเลขออเดอร์ ที่อยู่จัดส่ง และไทม์ไลน์ → กด Done → การ์ด BSW-177 ขึ้น **Reserved** |
| S8 | เปิด `/owner` (ใส่รหัส) → ตารางออเดอร์ (AG Grid) ให้เห็นแถวใหม่ → เลื่อนไปทางขวาให้เห็นเบอร์และที่อยู่ |
| S9 | กด **Send balance invoice** → ข้อความยืนยันขึ้น |
| S10 | (ต้องมีออเดอร์ที่สองที่ยังไม่ส่งใบแจ้งหนี้) กด **Refund** → ยืนยัน → ข้อความ "Refunded … back in stock" → เลื่อนลงไปตารางสต็อกให้เห็นแผ่นกลับเป็น available |
| S11 | ในส่วน **Add a slab with AI**: ใส่รูปไม้จากมือถือ ขนาด และราคา → กด **Write listing with AI** → ให้เห็นผล (ถ้าเวลาไม่พอ ตัดฉากนี้ได้) |

ขาดแค่ S10: ก่อนอัด S10 ให้จ่ายมัดจำอีกแผ่นไว้ล่วงหน้า (ไม่ต้องอัดตอนจ่าย)

## Part 4 · ตัดต่อใน Clipchamp (1–2 ชม.)
1. เปิด **Clipchamp** (มีใน Windows 11) → Create a new video → อัตราส่วน **16:9**
2. ลากคลิปทั้งหมดเข้ามา เรียงตามลำดับในตาราง Part 3
3. ตัดช่วงรอโหลดออก (เลือกคลิป → **S** เพื่อตัด) ช่วง AI กำลังคิดให้เร่งความเร็ว (Speed 2x)
4. **Record & create → Text to speech** → วางบทพากย์ทีละท่อน → Save → ลากไปวางใต้ภาพ
5. ใส่ข้อความบนจอ (Text)
6. **Content library → Music** เลือกเพลงเบาๆ แล้วลดเสียงเพลงเหลือ 10–15%
7. **Export → 1080p**
